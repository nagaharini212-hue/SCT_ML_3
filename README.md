# SCT_ML_3
# Cats and Dogs Image Classification using SVM

## Objective
To classify cat and dog images using a Support Vector Machine (SVM).

## Tools Used
- Python
- Google Colab
- OpenCV
- NumPy
- Scikit-Learn

## Dataset
Cats and Dogs Image Dataset from Kaggle.

## Project Workflow
1. Load Dataset
2. Preprocess Images
3. Resize Images
4. Convert Images into Feature Vectors
5. Split Dataset into Training and Testing Sets
6. Train SVM Model
7. Evaluate Model Performance

## Result
Successfully classified cat and dog images using Support Vector Machine (SVM).
